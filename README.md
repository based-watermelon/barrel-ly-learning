# barrel-ly-learning
Creating a model to play Donkey Kong using imitation learning and actor-critic reinforcement learning

## Trained Model & Dataset

The Behaviour Cloning agent and training dataset are available on Hugging Face:

- **Model:** [Barrelly_LFD](https://huggingface.co/based-watermelon/Barrelly_LFD)
- **Dataset:** [data_holdframe4](https://huggingface.co/datasets/based-watermelon/data_holdframe4)

The dataset contains state-action demonstrations collected from gameplay
and is used to train the Behaviour Cloning policy.
